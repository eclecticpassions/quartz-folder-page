
# Custom Quartz Folder Page Plugin

This custom FolderPage Quartz plugin adds one functionality: it allows you to exclude the automatic generation of a "page listing" section of all the content under that particular folder (index) page.

I added this feature because I am using [Dataview](https://blacksmithgu.github.io/obsidian-dataview/) + [Dataview Serializer](https://developassion.gitbook.io/obsidian-dataview-serializer/usage) to manage my own lists in [Obsidian](https://obsidian.md/). Graph view wouldn't show connections when the links are generated by Quartz.

## Usage

To exclude the automatic generated list from showing, on your index page of choice, add a front matter parameter called `hideList`:

```yaml
hideList: true
```

For example, to hide the list from showing in the "Blog" folder page, `https://example.com/blog/`, you would add `hideList: true` to `content/blog/index.md`.

## Install

1. To install this plugin to your Quartz site, run:

    `npx quartz plugin add github:eclecticpassions/quartz-folder-page`

2. To update the plugin, run it with the `--latest` flag like:

    `npx quartz plugin install --latest github:eclecticpassions/quartz-folder-page`

3. Set the `quartz.config.yaml` file to the following and choose your own options:

    ```yaml
    - source: github:eclecticpassions/quartz-folder-page
      enabled: true
      options:
        showFolderCount: true
        showSubFolders: true
        prefixFolders: true
    ```

4. If you already had the original Folder-Page plugin installed, you can uninstall it with `npx quartz plugin remove github:quartz-community/folder-page` or just turn it off in `quartz.config.yaml` by setting `enabled: false`

## @quartz-community/folder-page

Renders folder index pages showing a listing of all pages within that folder. Automatically generates virtual index pages for folders that don't have one.

## Installation

```bash
npx quartz plugin add github:quartz-community/folder-page
```

## Usage

```yaml title="quartz.config.yaml"
plugins:
  - source: github:quartz-community/folder-page
    enabled: true
```

For advanced use cases, you can override in TypeScript:

```ts title="quartz.ts (override)"
import * as ExternalPlugin from "./.quartz/plugins";

ExternalPlugin.FolderPage({
  showFolderCount: true,
  showSubfolders: true,
  prefixFolders: false,
});
```

## Configuration

| Option            | Type      | Default     | Description                                                                            |
| ----------------- | --------- | ----------- | -------------------------------------------------------------------------------------- |
| `showFolderCount` | `boolean` | `undefined` | Whether to show the number of items in the folder.                                     |
| `showSubfolders`  | `boolean` | `undefined` | Whether to show subfolders in the listing.                                             |
| `sort`            | `SortFn`  | `undefined` | A function to sort the pages in the folder.                                            |
| `prefixFolders`   | `boolean` | `false`     | Whether to prefix generated folder page titles with "Folder: " (e.g. "Folder: notes"). |
